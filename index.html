Importar Excel

Al importar un archivo se reemplaza completamente el catálogo actual: operaciones, referencias y parámetros. Si además marca la opción, se eliminan las cotizaciones guardadas. Antes de reemplazar se guarda una copia de seguridad.

Copias de seguridad / Guardado compartido

Si Supabase está configurado, el historial se guarda en la nube y se ve en cualquier dispositivo. Si no, queda solo en este navegador. En ambos casos puede descargar una copia JSON como respaldo.

Enviar cotizaciones por correo

Se genera un Excel con las cotizaciones seleccionadas. Si Supabase o Firebase Storage está configurado, el Excel se sube y el correo EmailJS incluye un enlace de descarga. Si no, el Excel se descarga localmente y el correo va sin enlace público.
